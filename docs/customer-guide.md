# Customer Guide

## What is delivered

1. JMeter test plan
2. Local mock server
3. Result analyzer
4. HTML report generator
5. Test plan and report templates

## How to replace the mock API

Modify the JMeter HTTP Request domain, port, path and request body. Keep the same result collection and analysis flow.

## Suggested enterprise workflow

Baseline test → ramp-up test → concurrency test → stability test → bottleneck analysis → capacity conclusion → regression test.
